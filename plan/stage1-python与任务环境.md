# 阶段 1 · Python 与可控任务环境（第 5–8 天）

> 目标：掌握完成实验所需的最小 Python 能力，制作一个无需网络和付费模型的任务环境。

准备：安装 Python 3；终端运行 `python --version`。本阶段只用标准库，所有写文件操作放在你新建的练习目录中。

## 核心概念

可复现研究需要固定输入、明确输出和可重置状态。先把“世界”做成简单的字典与文件，才容易看出 harness 本身是否起作用。不要一开始接入复杂框架。

## 任务清单

### ☐ 1-1 跑通 Python 的最小数据结构

- 在练习目录创建 `toy_harness.py`，亲手输入下面代码并运行；试着改变 `goal` 和 `steps_left`。

```python
state = {"goal": "找到答案", "steps_left": 3, "history": []}
action = {"tool": "lookup", "args": {"key": "alpha"}}
state["history"].append(action)
print(state["goal"], len(state["history"]))
```

- 思考题：列表、字典和字符串各适合存哪一类轨迹信息？
- **完成标志**：能修改、运行并解释 `state` 与 `action` 的每一个字段。

### ☐ 1-2 设计两个只读工具

- 建一个固定知识库 `facts = {"alpha": "A", "beta": "B"}`，写 `lookup(key)`；再写 `list_keys()`，返回所有合法键。不存在的键应返回明确错误，不抛出难懂的堆栈。
- 用同一套 `{"tool": ..., "args": ...}` 格式调用两个工具，拒绝未知工具名。先打印结果，暂时不需要模型。
- 思考题：为什么不应把任意 Python 表达式直接当成工具调用？
- **完成标志**：分别展示有效调用、未知键和未知工具的输出。

### ☐ 1-3 建立可重置的小任务集

- 写 6 个小任务，例如“查出 alpha 的值”“列出全部键”“查一个不存在的键并正确说明不存在”。每个任务保存目标、初始知识库与预期结果。
- 把数据写入 `tasks.json`；用 `json.load` 读入，运行前重建知识库，确保前一个任务的修改不会污染后一个任务。
- 自测：连续以不同顺序运行任务，初始输入是否完全相同？
- **完成标志**：可以加载 6 个任务，并说明怎样判定每个任务成功。

### ☐ 1-4 用 JSONL 保存可审计轨迹

- 每一步记录任务 ID、步骤号、动作、观察、剩余预算和时间。每行一个 JSON 对象，写入 `trace.jsonl`；将 API 密钥、个人数据等排除在日志外。
- 用 `json.loads` 逐行读回，检查步骤号连续、每步均有动作和观察。
- 思考题：如果只记录最终回答，你会失去哪些失败诊断线索？
- **完成标志**：留下可读取的 3 步样例轨迹，并能够复述每一步发生了什么。

你拥有一个固定任务集、两个受控工具和可读轨迹；后续阶段只需加入“选择动作”的部分。
